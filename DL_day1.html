[00:08:15] 1. AI vs Machine Learning vs Deep Learning

Introduction & Definition

Before writing a single line of code, we must understand the landscape. The terms Artificial Intelligence (AI), Machine Learning (ML), and Deep Learning (DL) are often used interchangeably, but they represent a strict hierarchy.

Definition Hierarchy
  • Artificial Intelligence (AI): The overarching discipline aiming to create systems capable of performing tasks that typically require human intelligence (reasoning, vision, learning).
  • Machine Learning (ML): A subset of AI containing statistical algorithms that allow computers to learn patterns from data without being explicitly programmed.
  • Deep Learning (DL): A specialized subset of ML that uses multi-layered Artificial Neural Networks to model highly complex, non-linear relationships, largely inspired by the human brain.
Artificial Intelligence (AI)
Machine Learning (ML)
Deep Learning (DL)

Why it Exists & Problem it Solves

Classical ML algorithms (like Random Forest or SVM) reach a plateau in performance as data volume increases. They also require manual feature engineering. Deep Learning exists to automatically extract hierarchical features from massive, unstructured datasets (images, text, audio) and continuously scale performance with more data.

[00:41:10] 3. The Perceptron Model

Definition

Introduced by Frank Rosenblatt in 1957, the Perceptron is the simplest form of an Artificial Neural Network. It is a single-layer neural network used for binary classification.

Step-by-Step Explanation

  1. Initialization: Receive an input vector $X \in \mathbb{R}^{d \times 1}$ and assign random weights $W$ and a bias $b$.
  2. Weighted Sum (Linear Transformation): Multiply each input by its corresponding weight and sum them up, adding the bias.
    $$ z = \sum_{i=1}^{d} w_i \cdot x_i + b = W^T X + b $$
  3. Activation (Non-Linearity): Pass the sum $z$ through a step function to restrict the output strictly between 0 and 1.
    $$ \hat{y} = \begin{cases} 1 & \text{if } z \ge 0 \\ 0 & \text{if } z < 0 \end{cases} $$
Common Mistake: The XOR Problem

A single Perceptron is a linear classifier. It can only separate data using a straight line. It completely fails on non-linear datasets like the XOR logical operator.

[01:10:05] 4. Architecture of an Artificial Neural Network (ANN)

How Information Flows (Forward Propagation)

In Forward Propagation, data moves strictly left-to-right. At layer $l$, the computation for the activations $A^{[l]}$ is given by:

$$ Z^{[l]} = W^{[l]} \cdot A^{[l-1]} + b^{[l]} $$
$$ A^{[l]} = f(Z^{[l]}) $$

Where $f$ is an activation function like ReLU, Sigmoid, or Tanh. This process cascades until we compute the final output.

5. Comprehensive Cheat Sheet

Important Definitions
  • Neuron / Node: The basic computational unit that takes input, applies weights, adds a bias, and passes it through an activation function.
  • Weights ($W$): Parameters that the network learns during training. They determine the importance of the corresponding input.
  • Bias ($b$): An additional parameter added to the weighted sum to shift the activation function, ensuring the neuron can activate even when all inputs are zero.
  • Forward Propagation: The process of passing data through the neural network from the input layer to the output layer to get a prediction.
  • Activation Function: A mathematical function applied to a neuron's output to introduce non-linearity into the network.

Memory Tricks
  • AI vs ML vs DL: Think of Russian Nesting Dolls. The biggest doll is AI, open it up to find ML, open ML to find DL at the core.
  • Weights vs Bias: Weights control the steepness (slope) of the decision boundary; Bias controls the position (intercept).
  • Linear vs Non-Linear: A Perceptron without an activation function is just a fancy Linear Regression model. Non-linearity (Activation) gives it the power to solve real-world complexities.

  • pytorch: The industry standard library for AI research and deep learning model building.
  • scikit-learn: Used for standard Machine Learning and preprocessing data before feeding it to DL models.
